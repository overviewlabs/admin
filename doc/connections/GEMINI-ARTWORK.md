# Gemini connector artwork

The Gemini connector reuses the reviewed Gemini color mark already bundled at
`ui/public/brands/adapters/gemini-color.svg`. The connector copy is stored at
`ui/public/brands/apps/gemini.svg` and uses the same artwork in both themes.

Source: [Lobe Icons, pinned commit a94750e3f5f8fc33757b839d85030e742284e43a](https://github.com/lobehub/lobe-icons/blob/a94750e3f5f8fc33757b839d85030e742284e43a/packages/static-svg/icons/gemini-color.svg).
The accompanying MIT license is `ui/public/brands/apps/LOBE-LICENSE`.

Reviewed on 2026-09-27. The SVG contains paths and internal gradient references,
with no scripts, event handlers, external resources, or embedded HTML. It renders
through the shared `AppLogo` component and keeps the existing connector frame.
